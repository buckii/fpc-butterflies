# Blooms & Butterflies image map

Every image in `images/` came from the original 59-slide PowerPoint (`Blooms & Butterflies EA.pptx`), extracted
from the slide relationship files so each one is tied to the slide it was actually used on. Files are prefixed with
that slide number. `shared_` files are UI pieces used on many slides. Every file is under 10 MB and at most 2000 px
on its longest side. Images with transparency are PNG so they can be overlaid on a background; opaque photos are JPG.

Original slide numbers below refer to the PowerPoint. The HTML in `index.html` has its own 38-slide numbering
(see `CLAUDE.md`), so a file prefixed `slide46` may be used on a different HTML slide.
